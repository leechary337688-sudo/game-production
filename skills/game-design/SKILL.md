# 游戏设计原则

> 用于吸引人的游戏的设计思维。

---

## 1. 核心循环设计

### 30秒测试

```
每个游戏都需要一个有趣的30秒循环：
1. 动作 → 玩家做某事
2. 反馈 → 游戏响应
3. 奖励 → 玩家感觉良好
4. 重复
```

### 循环示例

| 游戏类型 | 核心循环 |
|-------|-----------|
| 平台游戏 | 跑 → 跳 → 落地 → 收集 |
| 射击游戏 | 瞄准 → 射击 → 击杀 → 掠夺 |
| 解谜游戏 | 观察 → 思考 → 解决 → 前进 |
| 角色扮演游戏 | 探索 → 战斗 → 升级 → 装备 |

---

## 2. 游戏设计文档 (GDD)

### 基本部分

| 部分 | 内容 |
|---------|---------|
| **创意简述** | 一句话描述 |
| **核心循环** | 30秒游戏玩法 |
| **机制** | 系统如何工作 |
| **进展** | 玩家如何前进 |
| **艺术风格** | 视觉方向 |
| **音频** | 声音方向 |

### 原则

- 保持其活力（定期更新）
- 视觉有助于沟通
- 少即是多（从小开始）

---

## 3. 玩家心理学

### 动机类型

| 类型 | 驱动因素 |
|------|-----------|
| **成就者** | 目标、完成度 |
| **探索者** | 发现、秘密 |
| **社交者** | 互动、社区 |
| **杀手** | 竞争、主导 |

### 奖励时间表

| 时间表 | 效果 | 用途 |
|----------|--------|-----|
| **固定** | 可预测 | 里程碑奖励 |
| **变量** | 令人上瘾 | 战利品掉落 |
| **比率** | 基于努力 | 刷怪游戏 |

---

## 4. 难度平衡

### 流状态

```
太难 → 沮丧 → 退出
太易 → 无聊 → 退出
恰到好处 → 流 → 参与
```

### 平衡策略

| 策略 | 如何 |
|----------|-----|
| **动态** | 根据玩家技能调整 |
| **选择** | 让玩家选择 |
| **可访问性** | 为所有人提供选项 |

---

## 5. 进展设计

### 进展类型

| 类型 | 例子 |
|------|---------|
| **技能** | 玩家变得更好 |
| **力量** | 角色变得更强大 |
| **内容** | 新区域解锁 |
| **故事** | 叙事前进 |

### 节奏原则

- 早期胜利（快速吸引）
- 逐渐增加挑战
- 强度之间的休息节拍
- 有意义的选择

---

## 6. 反模式

| ❌ 不要 | ✅ 做 |
|----------|-------|
| 孤立设计 | 不断进行游戏测试 |
| 在有趣之前打磨 | 先制作原型 |
| 强制一种玩法 | 允许玩家表达 |
| 过度惩罚 | 奖励进展 |

---

> **记住：** 乐趣是通过迭代发现的，而不是在纸上设计的。
