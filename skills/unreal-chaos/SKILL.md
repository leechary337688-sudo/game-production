# 虚幻混沌技能

Unreal Engine的Chaos物理系统。

## 概述

本技能提供使用Unreal的Chaos物理系统实现基于物理的破坏效果、车辆和软体模拟的能力。

## 功能

### 破坏效果
- 创建几何体集合
- 配置破碎模式
- 处理碎片模拟
- 管理碰撞集群

### 车辆物理
- 实现轮式车辆
- 配置悬挂系统
- 处理空气动力学
- 管理车辆网络同步

### 布料模拟
- 配置布料资产
- 处理碰撞
- 管理约束条件
- 优化性能

### 物理场
- 应用力场
- 创建吸引/排斥场
- 处理噪声场
- 管理场相互作用

## 前提条件

- Unreal Engine 5.0+
- 启用Chaos（默认已启用）

## 使用模式

### 几何体集合设置

```
1. 从网格创建几何体集合
2. 配置破碎设置
3. 添加集群连接
4. 设置物理属性
5. 放置到关卡中
```

### 车辆设置

```cpp
// 在车辆移动组件中配置
WheelSetups.Add(FWheelSetup{
    WheelClass,
    BoneName,
    WheelOffset
});
```

## 最佳实践

1. 分析破坏复杂度
2. 对远处碎片使用LOD
3. 配置休眠阈值
4. 测试网络化破坏
5. 管理集群数量
