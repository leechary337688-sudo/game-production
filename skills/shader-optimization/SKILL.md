# 着色器优化技能

着色器性能优化技术。

## 概述

本技能提供优化着色器性能的能力。

## 能力

- 指令计数
- ALU优化
- 纹理采样减少
- 着色器变体管理
- GPU性能分析

## 最佳实践

1. 最小化纹理采样
2. 尽可能使用半精度
3. 避免分支
4. 批处理相似着色器
5. 在目标硬件上进行性能分析
