# Godot 2D 技能

用于 Godot 引擎的 2D 游戏开发。

## 概述

此技能提供了在 Godot 中使用瓦片地图、精灵和像素完美渲染创建 2D 游戏的能力。

## 能力

- 配置 TileMap 和 TileSet
- 设置 CanvasLayer 层级结构
- 处理像素完美渲染
- 实现 2D 摄像机
- 配置视差背景
