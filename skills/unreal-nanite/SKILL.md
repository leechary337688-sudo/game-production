# 虚幻纳米技术技能

虚幻引擎的纳米虚拟化几何系统。

## 概述

此技能提供了在虚幻引擎中实现纳米虚拟化几何的能力，无需传统LOD工作流即可实现高保真资产。

## 能力

### 网格配置
- 在网格上启用纳米技术
- 配置备用网格
- 处理位移
- 管理精度设置

### 流式传输
- 配置流式池
- 处理网格流式传输
- 管理内存预算
- 优化加载

### 集成
- 与Lumen结合使用
- 处理材质约束
- 与世界分区集成
- 管理可见性

### 优化
- 配置集群剔除
- 处理过度绘制
- 管理三角形预算
- 分析纳米性能

## 先决条件

- 虚幻引擎5.0+
- 支持SM5+的硬件
- 高多边形源网格

## 使用模式

### 启用纳米技术

```
1. 导入高多边形网格
2. 打开静态网格编辑器
3. 在详细信息面板中启用纳米技术
4. 配置设置
5. 应用到实例
```

### 设置配置

```
纳米设置：
- 位置精度：自动
- 三角形百分比：100%
- 备用相对误差：1.0
- 位移：为地形启用
```

## 最佳实践

1. 为主角资产使用纳米技术
2. 保留备用网格
3. 监控GPU内存
4. 在目标硬件上测试
5. 使用纳米可视化工具
